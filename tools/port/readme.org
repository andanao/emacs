#+TITLE: Migration scaffolding

Scripts that turned the literate config into this tree.  They exist so the
port can be re-run, not because anything here needs them at runtime.

*Delete this directory at cutover.*  Once ~~/.emacs.d~ points at this repo the
literate config is gone and none of this has an input.

* Why it is still here
Main kept moving while the port was being done.  Re-running the split against
a newer ~readme.org~ is a few minutes; redoing it by hand is not.  That is the
only reason to keep them.

* Re-running the port
Never tangle from a worktree while the old config still lives: one target,
~~/.config/rustfmt/rustfmt.toml~, is an absolute path and a stale tree would
overwrite live config.  Tangle a copy.

#+begin_src shell
tmp=$(mktemp -d) && cp ~/git/emacs/readme.org "$tmp/" && (cd "$tmp" \
  && emacs --batch -l org readme.org -f org-babel-tangle)

python3 tools/port/port.py "$tmp" .
#+end_src

~PORT_MECHANICAL=1~ keeps the sections the migration deliberately dropped, so
the output is byte-equivalent to the tangled original.  Without it the drops
in ~manifest.py~ apply.

* Before cutover
One thing outside this repo breaks, and it breaks at cutover rather than
during the trial.

~~/git/konfig/work.el~ line 44 does

#+begin_src emacs-lisp
(add-to-list 'org-babel-auto-tangle-file-list k2/config-file)
#+end_src

and that variable no longer exists, because the tangle-on-save section that
defined it is gone.  Deleting the line is the whole fix.  It is left alone
here because konfig is a separate repo and the work split is not this job.

While running side by side, ~work.el~ also calls ~(server-mode)~, which wants the
socket the live Emacs already holds.  Harmless once there is only one Emacs;
until then the trial daemon needs its own ~server-name~.

* Checking it
| ~verify.py REF .~   | the faithfulness gate: sorted top-level forms must match |
| ~review.py REF .~   | one line per remaining difference, for sign-off          |
| ~reorder.py REF~    | how far each section moved, and the invariants that hold |
| ~parsecheck.el~     | every file reads, no package set needed                  |
| ~compile-check.sh~  | byte-compile against the flake's packages                |
| ~startup-check.sh~  | start a throwaway daemon and look for a backtrace        |

~analyze.py~ and ~outline.py~ were used to design the split and are kept only
because they explain where ~manifest.py~ came from.
